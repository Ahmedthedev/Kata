# Kata Tondeuse à Gazon

Ce projet est une implémentation Java 17. 
Il applique les principes du **TDD**, de la **Clean Architecture**, et utilise Maven pour la gestion de dépendances.

---

## Objectif

Simuler le déplacement de plusieurs tondeuses automatiques sur une pelouse rectangulaire, selon des instructions définies dans un fichier d'entrée.

---

## Stack technique

- Java 17
- Maven
- JUnit 5
- AssertJ
- Lombok
- SLF4J + Logback (logging)


## Lancer l'application

### Compilation :

```bash
mvn clean compile
```

### Lancer les tests :

```bash
mvn test
```
